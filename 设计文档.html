沉债｜打捞玩法演示 · 设计

状态：用户 2026-10-14 定：只给人看打捞这一个玩法，按玩法演示的规模做；不是整款游戏。以前做的版本（001—038）做得不好，已删除。 更新于 2026-10-14。

本文件是《沉债》打捞玩法演示的唯一设计文档，原地打磨。只有打捞：船员配队、鉴宝、战斗、债务、装备与换船都不做；以前那版综合玩法和持续探索的设计只在 Git 历史里。

用户已定：3D、诡异海洋冒险、单机、固定 1920×1080 横版；移动和下网消耗燃料；重网直上直下；玩家调臂后按 A，回收和洗泥自动进行；任何值得尝试的打捞目标都有参考；浅水能看见海底，越深越难辨认；目标是真实沉船这样的具体事物；活物在海底真实活动；海底有自己的生态。

0. 演示的范围

  • 给谁看： 一个人坐下来两三分钟，看懂并看爽打捞这一个玩法。
  • 一个地方： 归潮沙湾一片海，一艘侧卧在缓坡上的中世纪木帆商船。三处现场：通透浅滩、沉船、下坡。一共 6—8 个能下网的地方。
  • 一圈： 从港外航路开船出发 → 浅滩上的线索 → 顺着线索找到沉船 → 下几网 → 至少一次珍贵物的揭晓 → 船员搬运入舱 → 网都下完或油见底时，出一张这一趟的收获单（捞上了什么）→ 可以再来一次。
  • 保证： 至少一件珍贵物（铁箍小匣里的银币匣）一定在这一圈里出现。
  • 自动演示： 一个入口，点一下就从头自己玩，两三分钟走完一圈，尽快放出精彩的部分；Esc 随时接管。
  • 不做： 其他海域和新生成的海域；港口、补给、航次账、海图和小海图、收获册；蟹和鱼群以外的生物；存档和读档；局外成长、经济、联机、商店。

1. 玩家在享受什么

开船经过一片活着的海底，看出值得打捞的东西，选好船位和时机，把自己看中的那一网带上来。

玩家应该能说：「那条沉船的货物顺着坡滚下去了」「蟹刚才翻出了一个硬东西」。三种满足感：

  • 看懂了： 从地形、残骸和生物行为中发现机会，有依据地改变判断。
  • 捞准了： 停对船位，臂端覆盖合适的一组东西，或等到活物停在容易捕获的位置。
  • 真的带回来了： 海底少了刚才那件东西，甲板上多了对应的实物；泥退去后，完整外形比水下看到的更丰富。

基本观察始终免费。一次判断失误损失的是已经预告的作业油和这次机会。

2. 一圈打捞

航行发现线索 → 换角观察实物、地形和活动 → 选船位与作业面 → 调吊臂 → A 下网 → 自动垂直起吊 → 船员洗去厚泥 → 揭晓并展示整网收获 → 快速回到大视野，立刻决定下一网；船员同时在后台搬运入舱。

阶段玩家做什么得到什么信息代价
观察停船、转动观察角度位置、轮廓、遮挡、活动免费；观察时船保持位置
移船为视线、臂展或垂直通路选船位新的观察面、可覆盖区域航行油
调臂旋转和伸缩，让臂端对准落点网口足迹、估计触底面、这一网的作业油免费
下网按 A入水和沉降的真实过程预先确认的整次作业油
回收看网收紧、提起、转回甲板网包体量、活动迹象，内容仍被泥遮着自动完成，不追加操作或扣费
揭宝看船员冲洗逐步露出的线索，后段确认完整实物自动完成；A 加快冲洗
继续下一网，或结束这一趟已捞的地方、剩下的机会由下一次移动或下网决定

收尾： 6—8 个网位都捞过、或油不够再下一网时，这一趟结束：出一张收获单，列出这一趟捞上的每一件和总价值，按一下重新开始。油的总量按「认真捞完这一处还略有余」来定，不用来卡人。

3. 水下信息：从实物逐渐退成轮廓

深浅连续变化。 水面通透程度、水下可辨距离和物体大小共同决定能看见什么，连续过渡，不会跨过一条线整件变黑或消失。

环境看见什么主要判断仍然未知
透水浅滩沙纹、石头、海草、散落货物，生物的朝向和活动捞哪一组、从哪里下网箱内内容、泥下部分
坡与中层水大体结构可辨，细节偏蓝、边缘变软，前后遮挡仍成立是残骸还是地形，哪一面露得更多材质、残缺程度、结构里藏的东西
下坡深处船身走势、较大的轮廓；近灯处有局部证据结合大结构和散落方向缩小落点大部分身份和完整形态
局部泥水或密草泥云、草叶挡住视线换角度、换作业面，或先捞旁边看得清的被遮住的那一块

「阴影」分开做：物体本身模糊的轮廓、物体投在底面的影子、深水地形的暗区、海草和泥云的遮蔽，各有自己的形状和变化原因。

角度变化有空间依据。 镜头围着船和作业区转：换角能看清船肋之间的货物、发现坡后露出的棱角、避开水面反光。物体随透视改变投影，世界位置不变。折射和波纹的晃动以能持续判断落点为准，不靠盯住一瞬间的几像素缝隙下网。浅水的东西不会等网口悬在上方才突然出现；深水的未知物也不会因为准星扫过就漏出名字或身价。

始终有参考。 参考先回答「为什么值得看这里」，再回答「网落哪儿」：暴露物看自身轮廓和相对位置；半埋物看突出的硬边、泥脊、刮痕和连着残骸的散片；深处看船体走势和浅处连续的残骸；活物看位置变化、停留点、爬痕和被翻动的泥；纯地形也能看出「这里没有值得下网的证据」。基础回声测深只给粗略区域、深度和在不在动，不给价值、品质或推荐落点。

4. 现场：中世纪木帆商船

船要像船。 一艘宽腹中世纪西方木帆商船侧卧在缓坡上：弯曲的木船壳、龙骨和外露的肋骨、抬高的首尾楼、断桅和残留帆索，破损但连贯；从几个角度看都认得出船首、船尾和有深度的船腹。

先找到它。 一圈从尚未看到沉船的港外航路开始：船真的开过去、真的耗油，先遇到浅滩的线索和散落物，再沿线认出沉船。不把船摆在沉船正上方，不瞬移，不预先列出作业点。

三处现场，三种选择：

  1. 通透浅滩： 沙纹、摆动的海草和小鱼；泥里露出半个铜筒，旁边是看得清的零件，几米外躺着一副锚。一网可以稳妥地兜走一小组，也可以把覆盖留给半埋的主件。
  2. 沉船： 外侧散货看得清、容易覆盖；甲板缺口和两道露天舱口里的货引人好奇，但要找网能垂直进去的船位；有顶的船舱从外面看得见货，网却穿不过甲板，只能走露天缺口。蟹在舱沿和船首之间觅食。
  3. 下坡： 沿货物滚落的方向往坡下，有一处被泥盖住、证据较弱但有来源可追的半埋件，旁边还埋着一截船材（硬物）。

打捞对象。 独立物件（铜筒、陶罐、铜件、旧缆）、一组同源的货、和活物（蟹）。东西在进入这片海时就生成并固定，不在按 A 后临时抽奖；伴随物和主物有因果（商船旁是信筒、封存货袋、舱口碎片，散落沿坡和船体缺口分布）。超出网口、被固定在结构上的部分是沉船本体，不能整件捞走。

疏密。 宝物少，普通货撑起这一趟；三处之间是草床、沙坡和礁脊，共享同一场事故的线索，不是三座奖品岛。单个船位通常只有一处值得下网。货取走后留下空位和网痕，不会补回来。

用场景引出想象。 船头还朝着岸边，货舱门却向外翻开；几个信筒顺坡散落，泥里又找到一件同款。诡异感来自少量违反常理的现象：看懂了普通生物以后，才看见一个逆流移动的大轮廓经过（只出现、不攻击、不能捕）。

5. 下网

重网怎么工作。 配重网架从臂端正下方垂直下沉，到达选定作业面后底沿自动内收，兜住网内能收的东西和表层泥，再垂直提起；回到安全高度后吊臂才把它转回甲板。玩家只操作船位、观察角度、臂端水平位置和下网时机；A 前可以反复调整，A 后位置锁定。没有张力、连按、反应或拉扯小游戏。网口足迹表示物理覆盖范围，不显示「保证命中」。

空间判定。

  • 静态物件按闭网时的实际位置、体积和能不能收来判断；小件完整落在网口里才算收到。同一网可以收到多件真实存在的东西。
  • 大物伸出网外时只收走附近的独立碎件。
  • 半埋物只有露出部分和埋深允许时才能收；深埋的大件给看得懂的限制，不诱导连续空投。
  • 沉船本体和固定结构事先说明不能整件收。碰到事先看不清的硬物，设备自动停止深入并收回，保留已兜住的小件；这一网的作业油已经花掉，不追加罚款。
  • 作业时船保持位置；燃油在确认时保证整次收放，不会因为油不够让网卡在水下。

活物按闭网时的位置结算。 按 A 时不锁定生物，也不先算出结果再播逃跑。网下沉期间生物照常行动；闭网时真正在网里的才收进来，之后在网里挣动。蟹每次停留的时间够这个水深下一网还有余量；不会一按 A 就读到输入瞬间闪开。

燃油。 停船观察、等生物、转镜头、调臂都免费；开船和每一网扣油。屏幕上一直看得见当前油量和这一网的作业油。停船时船位稳定，不漂移。

6. 活物和生态

这里只做两种生物和一条看得见的因果：

生物自己在做什么玩家读到的信号和打捞的关系
翻泥的蟹在船首、舱沿和散货之间往返，停下翻泥，受惊就退回遮蔽移动的身体、划痕、渐散的泥团翻开原本就埋着的小件（一枚印章）；自己也能被兜上来
海草间的小鱼群在草边聚散，船或网靠近时成片让开，再慢慢回来成片的避让说明哪里有动静；不是哪里有鱼哪里就有宝

一条因果： 水流推动草叶和悬沙 → 草和残骸给遮蔽 → 蟹在遮蔽和食源之间活动、翻泥露出东西 → 船和网的扰动让它们短暂改变行动。生物在玩家没瞄准时也在动；切换视角不重置，暂停才冻结。翻泥只露出原本就埋着的东西，不凭空生成物品。

作业留下什么： 网触底扬起局部泥沙、压倒草叶，在回收和冲洗期间恢复可见度；取走的东西真的离开海底，留下空位和网痕；被挡住的一小片可能露出来。

7. 揭宝

期待分三层： 那是一条什么船、货为什么散在这里；这一网能带走哪几件，泥里的弧面是器物的一角还是一块壳；上船后外层退去，实物完整吗、多大、同网还有什么。水下能看清大致类别和体积，不能提前交出最终答案；水下看到的和最终实物对应，不会在洗泥时把锚变成另一件宝物。

连续的揭晓过程。 上甲板的是一整团被厚泥、结壳、旧网和杂物包住的收获，不是几件干净模型盖一层薄泥。玩家认得出水下那一角，但还不能确认是什么：前段冲掉外壳，中段露出局部轮廓和材质，后段才露出关键特征和完整物件。名字、品质和价值到揭晓时才出现，字幕和列表都不提前说。

珍贵物的五个连续画面：

  • 预兆： 网包落下的重量和动静，让人意识到这一网不一样。
  • 露头： 水流冲掉表层，露出和水下观察对得上的一角。
  • 确认： 泥垢洗净，主物外形露全；一个伟大的揭宝高光，镜头、声音和特效一起服务于「终于知道是什么」，清楚地亮出实物和名字。
  • 展开： 给完整收获稳定的观看时间，同网的伴随物也看得清；普通物件也有明确的获得反馈。
  • 留下： 展示结束，快速回到能看船和海的大视野、恢复操作；船员各搬一件，几个人同时走过去、拿起、搬进船舱，货物经过舱口遮挡后才离开甲板。船可以马上开走或再下网。

时长： 普通清洗 4.2 秒、珍贵 5.4 秒；展示停留普通 2.25 秒、珍贵 3.2 秒；拉回大视野 1.25 秒。清洗自动进行，A 加快。

搬运只是动画。 收获在揭晓那一刻一次记入，搬运不重复增加或丢失物件。搬运的数量、排队和动画完成与否，不影响开船、油、臂端、下网、回收或下一次洗泥，不以「甲板没清空」「船员正忙」禁用任何操作。船移动时搬运跟着甲板走。开船和停船时，船员有值守、整理缆绳、巡视和检查设备的动作，不站着发呆。捞上来的蟹由船员放进甲板上的水槽，只作画面。

8. 自动演示

  • 一个入口：点一下，机器人从头开始玩这一圈，用的就是玩家的操作（摇杆、调臂、A），不瞬移、不发奖、不读隐藏的网位。
  • 尽快放出精彩部分：开局不久就有第一网，一圈里经过浅滩、找到沉船、下几网、一次珍贵揭晓、船员搬运，两三分钟走完；一圈完了出收获单，接着再来一圈。
  • Esc 随时接管：保留船位、油、收获、海底和船员的样子，正在进行的那一网自然做完，机器人不再接回。

9. 画面和操作

  • 固定 1920×1080、16:9 逻辑画面，窗口只整体等比缩放留边，看见的世界范围不变。风格化 3D，全部用代码画，世界里的东西有真实体积、前后遮挡和水下的空间关系。
  • 作业视角兼顾船、吊臂末端和目标海底；转动观察改变视线，镜头不能穿进沉船内部。近景冲洗镜头和作业镜头之间方向连贯，回来时沿用下网前的方向。
  • 手柄动作少而稳定：开船、换角观察、调臂端、A 下网；观察、开船、调臂有清楚的模式提示，避免为转视角误开船烧油。
  • 常驻只留当前要的：油量、臂端作业范围、估计水深、明显的作业限制；收获时再显示这一网。目标的身份和品质不靠水下界面提前泄露。
  • 关键判断靠大轮廓、运动方向、结构关系和简短文字，不只靠微小闪光、颜色或音效。晃动和折射强度可调。

10. 验收

通过规则检查只能证明一致；想不想看海底、想不想下网、想不想看收获，以实际试玩为准。

  • 一圈从港外航路开始，实际开船后才发现沉船；从两侧都认得出中世纪木帆船的船壳、首尾楼和断桅，露天舱口仍能垂直下网。
  • 浅水看到锚和半埋铜筒，能主动选其中一个；两者不是一团相同的黑影。
  • 从另一面看到货舱里的物件，仍要找到网能垂直进去的位置；有顶的船舱网穿不过。
  • 活物在按 A 前后连续运动：下网时它在原地、闭网时已离开，结果是没捕到它，旁边覆盖到的东西照样带回。
  • 蟹翻泥露出事先埋着的东西，玩家能指出新证据来自哪个动作；东西不会因翻泥凭空生成。
  • 网包上船和清洗前段仍看不清最终身份，关键特征在后段露出；揭晓后能说清获得了什么，并亲眼看到镜头拉远、船员各搬一件入舱。
  • 两个船员各搬一件时立刻开船，并在新落点下网；搬运不取消、不锁操作、不延迟收获、不重复结算。
  • 网都下完或油见底时出收获单，重新开始后海底和收获从头来过。
  • 自动演示点一下就开始，两三分钟内有珍贵揭晓，一圈完了接着下一圈；Esc 接管后状态不变、机器人不再接回。
