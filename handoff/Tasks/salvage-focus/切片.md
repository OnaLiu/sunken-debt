# 沉债 · 切片

这一份放切片的自动演示路线：点一下就从开始页自己演到终点，同一条路线看的人也能自己上手玩一遍。一段一节，每一节从这一段的开场写起；切片就是这一段的 N 小段接起来的那一条。路线以外的不做，做游戏的会话只做这条路线上出现的东西。每一步一行写演示里发生什么、要让看的人感到什么，下面接着写怎么演；要做成成品的东西指向它在设计的哪一份、哪一节，细节照那里做。具体的数和玩家看到的字不在这里，在 `配表.md`。

---

## 第一段·归潮沙湾

### 这一条路线是什么

一条小打捞船从港外开出去，顺着海底的线索找到一条沉了的中世纪商船，一网一网把泥包捞上来、冲开才知道是什么；回港开舱，才知道这条船连同一大笔债归了自己。之后一趟比一趟捞得多：船坞里升级，甲板码满一起冲，雇来的吊机手替你下网，最后一网赌在深槽边上；带着这一趟的收成还清债本第一页，下一片更深的海亮起来。

看的人要感到：海里看见的就是捞上来的，冲开那一下有盼头；花出去的每一笔钱都在船上看得见、在海上用得出来；手上的事越来越少、收成越来越多；海越往下越不对劲。看完想再出一趟，想看下一片海底下是什么。

走的是 `玩法.md`「核心循环」的一整圈：出海 → 捞 → 开舱 → 船坞 → 还债 → 再出海。前三小段就是用户 2026-11-26 点过头的三小段，在路线上是游戏里他认过的样子，不重做；后三小段长在它们上面。

一共三潮，大约十二分钟：第一趟三分多钟，船坞一分钟以内，第二潮四分钟上下，第三潮两三分钟，还债一分钟。

### 一步一步

#### 小段 1 · 第一趟（三小段，照游戏里认过的样子）

这一小段怎么演是做三小段时定的、用户看过点了头，下面照游戏现在的样子写下来，不重排。

1. **标题：** 镜头从水面上看着归潮沙湾，水底下隐约躺着一条船；选「开始」或「自动演示」。感到：底下有东西，想下去看。
   - 怎么演：标题画面的机位看着主沉船；按下去镜头从标题机位一路飞到船后，接上开船的镜头，中间不黑场。
2. **港外航路出发：** 左上横幅「港外航路」，一支方向箭头指着浅滩那根标杆；W 往前开，船员在甲板上值守、整缆。感到：我开着一条小打捞船出海了，要往那边去。
   - 怎么演：跟船的镜头（`玩法.md`「镜头」）；画面下方那一条只写第一次要用的键，开过一次就收起。
3. **通透浅滩：** 横幅「通透浅滩」；沙纹、海草、小鱼，泥里露着半个铜筒，旁边几样零件，几米外一副锚；每一处能捞的地方上面一支铜色箭头。鼠标指上去，白圈吸到那一处，小牌写「左键 下网」；按下去，吊臂转过去、网直上直下落下去、兜住、提起、砸上甲板，船员拿水管冲，看清形状那一刻揭晓。感到：海里看见的就是捞上来的，冲开那一下有盼头。
   - 怎么演：照 `时刻和效果.md`「揭宝的细节」：网包砸上甲板画面一顿、船身一沉；看清就崩，名牌和光束；揭完拉回大视野，船员搬一件进舱，不卡下一步。
4. **顺着船板：** 浅滩下过一网，箭头转向东南，海底一块接一块散着断船板、桶板、断缆头；经过一块，箭头就转向下一块。感到：在追一条线索，前面有什么。
   - 怎么演：快到一块时箭头先转过去；路上没事发生的那一截船开得快，不停。
5. **看见沉船：** 四十来米外，镜头偏过去看一眼：一条宽腹的中世纪木帆商船侧卧在缓坡上，断桅、破甲板、敞开的货舱，船头朝着岸；一道光从船尾扫到船头。感到：找到了。
   - 怎么演：偏过去这一眼一秒多就回到船后，不拦开船。
6. **深槽边，大轮廓第一次经过：** 开到沉船一带、离深槽近了，横幅「深槽」；坡下的小鱼先成片散开，随后一个很大的轮廓逆着水流从深槽里慢慢游过去，低低的心跳；它不攻击，也捞不着，游回深槽底。感到：下面还有东西，这片海不只是一条沉船。
   - 怎么演：照 `世界和内容.md`「活物和生态」：群体反应先出现，轮廓随后才看到；镜头不切过去，看的人自己看见。
7. **在沉船一网一揭：** 船边的陶罐、铜锅、箍桶一网一网捞；蟹在舱沿翻泥，翻出的泥里露出一角硬边，那里亮一圈（铜印）；断舱里那一包更沉、砸下来更重，冲开露出一线银光，银币匣浮起来、曝光、光束、号角。感到：这一网不一样，赚到了。
   - 怎么演：银币匣照 `时刻和效果.md` 珍贵物的五个画面：预兆、露头、确认、展开、留下。
8. **坡下那盏灯：** 在沉船下过两网，箭头顺着船尾指向坡下，深槽里冒上来一大串泡；坡上一盏铜灯偏蓝、只看得出轮廓，下一网把它兜上来。感到：越往下越看不清，也越值钱。
9. **按住 Q 回港：** 打捞时画面下方那一条写着「按住 Q 回港」；按住一秒，模式牌翻成「回港」、小表盘走满；船员擦手、吊臂收回，镜头扎进舱口。感到：这一趟到头了，收成都在舱里。

#### 小段 2 · 开舱、债本、船坞（三小段，照游戏里认过的样子）

1. **开舱：** 舱里一块红布，东西从便宜到贵一件件落下、挂签（名字、从哪儿捞的、多少钱），价值飞进总数；银币匣最后从光里落下压轴，盖入舱章；底下列着这一趟做到的事（找到了沉船、见过深槽里那个东西）。按「进港」。感到：这一趟的收成摆在眼前，值了。
   - 怎么演：照 `时刻和效果.md`「揭宝的三种规模」开舱那一段；按住左键或空格加快。
2. **第一次翻开债本：** 最上面一句「这条船连同它的债，现在都归你了。」；还欠一大笔，分四页并排，每一页上一把锁和一片海的名字，指着一页亮出「还清后开放」哪片海。感到：原来是背着债出海的，难怪要捞；第一页不算远，后面一页比一页大。
   - 怎么演：开舱盖完章接着翻开，不另停；这是主角为什么在这里的那一下（`世界和内容.md`「债的故事」）。
3. **船坞：** 船停在灯塔那边港口的码头，镜头慢慢绕着船转；船上网口、油箱、甲板、水泵各一块铜牌，牌子底下是价签。鼠标指着哪块，卡贴在牌子上方：几级、升了以后那一行（图标和前后的数）、一句说明、购买和价钱。买甲板加宽、网口、油箱、水泵：每买一样，船员走过去弯腰装上，油桶一顿落在甲板上、网架大一圈、两舷翻出加宽的平台。钱不够的写「钱不够」。感到：花出去的钱在船上看得见。
   - 怎么演：照 `玩法.md`「设备：船坞」；船员走过去那一截短，装上那一下给看清。
4. **出海：** 按 E 出海：舱盖拉上的浪声，黑一下，船已经在港外航路。

#### 小段 3 · 第二潮（三小段，照游戏里认过的样子）

1. **这一潮重铺过：** 船直接开去沉船（走熟了，浅滩横幅、看见沉船那一眼不再演）；海底的地形、沉船、船板都在原处，货换了一批，从舱口和船腹冲出来的散在船边和坡下。感到：同一片海，这一潮不一样，又有新东西捞。
2. **码包：** 网口大了一圈，同一处多罩一两件；挑一处按一下，网还在水里就点好下一处（箭头变绿），网收回来自己接着下；泥包不冲，码在甲板上；第一包码上去时甲板那一排底下说一次「码满自动开冲」。感到：一网接一网，不用等。
3. **一甲板一起冲：** 码满，几个船员各拿一根水管，镜头拉到看得见整个甲板，泥壳一包接一包崩开，从便宜到贵、越崩越快，每一件飞进货格，这一批的总数一份份加上去；最贵的那一件（有银币匣时是它）最后单独走一遍珍贵物的确认。感到：一甲板一起开，比一网一网爽得多。
   - 怎么演：照 `时刻和效果.md`「揭宝的三种规模」一甲板一起冲；冲的时候指针收起。
4. **再码一甲板，回港：** 再码一甲板冲完，按住 Q 回港；收获单比上一趟多一行「比上一趟」。感到：一趟比一趟多，看得见在长。

#### 小段 4 · 吊机手

1. **第二次进船坞，雇吊机手：** 收获单「进港」进船坞。钱这时刚够一样大的：吊机前那个扳手柄的船员头上多一块铜牌，指着他，卡上写「吊机手」、升了以后那一行是下网的那只手从「你」换成「他」（图标），一句说明、价钱。点购买：他戴上手套，吊机前立起一张带顶棚的座子，他坐上去握住手柄。感到：有人替我干活了。
   - 怎么演：和买设备同一套：牌子、卡、购买、船员当场装上（`玩法.md`「设备：船坞」）；这一回装的是人自己，坐上去那一下给看清。他是船上原来就在的那个人，看的人认得出。
   - 演示只买这一样，钱花到只剩一点；别的牌子上的价签照旧亮着，看得出下一趟还有得买。
2. **出海，开到沉船旁停下：** 船一停稳，吊机手转头看一眼，白圈自己跳到他挑的那一处（那一处的箭头上多一个他的小头像），吊臂转过去、网落下去。演示的鼠标一下没动，画面上亮着的只有 W A S D。感到：我只开船，他在下网。
   - 怎么演：他挑之前停一拍、头转向那一处，看的人看得出是他在挑；他下的网和你下的一个样子、一样的分量（`时刻和效果.md`「吊臂的分量」）。
3. **你挑停在哪：** 船边那几堆捞完，演示开到断舱那一侧再停，他接着下；泥包一包包码上甲板，码满自己开冲，一甲板一起冲照小段 3 的样子。感到：手上的事从「这一网下在哪」变成「船停在哪」，甲板照样满。
   - 怎么演：开船的那一截路上没事，船开得快、不给看完；停稳那一下他就动手，不等。

#### 小段 5 · 最后一网（捏一把汗）

1. **油只够一网：** 第三潮快到头，油条发红，心跳快起来，模式牌写「这一趟快结束了」。吊机手看着船边剩下的一小堆碎陶罐，正要下。深槽坡上有一点铜绿的反光，上面是一个橙圈，旁边泥里露着一截埋着的船材。感到：就剩这一网了，下在哪？
   - 怎么演：油和心跳照 `信息.md`「常驻在屏幕上的」、`时刻和效果.md`；这时镜头还在船后，坡上那一点反光在画面里看得见。
2. **你接过吊机：** 演示的鼠标挪到坡上那一处，小牌写着橙圈的意思（会刮到硬东西，埋着的会掉）和这一网的油；按住左 Shift 拉近看：泥里半露着一盏铜灯，紧挨着那截船材。松开，左键按下去：吊机手松开手柄往后让了一步，这一网是你的。感到：要冒险，赌一把。
   - 怎么演：看的人看得见鼠标挪过去、按了 Shift、按了左键（`平台和发行.md`「自动演示」）；吊机手让开那一下给看清，是他看着你接手，不是他自己停了。
3. **网下去，大轮廓经过：** 网往坡下的蓝暗里沉；坡上的小鱼先成片散开，那个大轮廓又从深槽里游上来，逆着水流从船底下慢慢过去，影子扫过网绳；心跳最快。网触底，刮到那截船材：网架一震、闷响一声、扬起一团泥，网停住，往回收。感到：心提到嗓子眼，刮到了，灯还在不在？
   - 怎么演：大轮廓经过和网触底落在同一下，是这一段最紧的那一刻；镜头不切、不拉近，一直在船后，看的人自己看着影子扫过网绳。大轮廓照旧不碰船、不碰网（`世界和内容.md`「活物和生态」）。
4. **提上来，灯还在：** 网包出水，比别的都沉，砸上甲板那一下最重；这一网码上去甲板正好满，开冲，铜灯那一包压轴：水冲开顶上一块，露出一线铜绿，再一下崩开，铜灯浮起来、曝光、光束、号角。吊机手冲你点一下头，坐回手柄后面。油不够再下一网，自己收工。感到：赌赢了，松一口气。
   - 怎么演：刮到硬东西照 `玩法.md`「下网」空间判定：设备自己停住、收回，已经兜住的照样带上来；铜灯露在外面，所以在；压轴照珍贵物的五个画面。

#### 小段 6 · 还清第一页

1. **开舱：** 这一趟的收获单比上一趟又多一截，铜灯最后落下压轴，盖章。感到：这一趟最多。
2. **债本的牌子亮了：** 进船坞，右上「债本」那块牌子亮着（钱够还一页了）。按 Q 翻开，第一页底下那个按钮从「还差」换成了「还这一页」。感到：够了。
3. **还这一页：** 点下去，手上的钱一份份数进第一页，那一页盖上一个「已还清」的章，翻过来，背面画着下一片海：一道窄峡，几十条不同年代的沉船叠着躺，偏蓝，每一条的船头都朝着同一个方向，和沙湾那一条一样；下面写着这片海的名字「锈钟峡」，「还欠」那个总数少了一截。感到：往前走了一大步；下面那片海不对劲，想去看。
   - 怎么演：章盖下去和翻页各一个声音（`美术和声音.md`「声音」的债本翻页）；翻过来那张画停到看清就走，不读字也看得懂。
4. **合上，站在码头：** 合上债本回到船坞，镜头绕着这条已经换了一身设备的船转：大一圈的网架、油桶、加宽的平台、吊机前坐着的吊机手；「出海」亮着。演示到这里结束，回到标题。感到：这条船是我一点点攒起来的，还想再出一趟。
   - 怎么演：这一版锈钟峡还没做，债本那一页写「已还清 · 锈钟峡还没做」；路线到这一下结束，不往锈钟峡开。

### 让人捏一把汗的那一下

小段 5：油只够一网，只剩冒险的那一处值得；网下到坡上的那一刻大轮廓从船底下经过，网刮到埋着的船材停住往回收，看的人不知道灯还在不在。紧张靠看得见的后果撑起来：油条、心跳、橙圈的那一句、刮到时网架那一震，不靠字。

### 不懂这些的人看得懂吗

这里用到的只有两样不是人人熟的：中世纪的木帆商船、背着债出海。船靠画面就懂：侧卧的木船、断桅、货舱，看着就是一条沉船；债靠第一次翻开债本那一句和四页并排的锁和海名就懂：还清一页、开放一片海。打捞船、吊机、网、水管冲泥都是看得见的动作和后果，不用知道真的打捞怎么干。诡异的那几样（逆流的大轮廓、船头都朝着岸）是加分：看不出也不耽误看懂一路在发生什么。

### 要做成成品的

**看的人一直看着、听着的：**

- 远看：跟船的镜头从上往下看，船在画面正中，船边的海底看得见；浅滩通透发绿，往沉船、坡下一路偏蓝变暗，深槽只看得出大轮廓（`信息.md`「水下信息」）。近看：按住左 Shift 拉近的那一块，泥、草、半埋的东西（`玩法.md`「镜头」）。
- 天光和天气：一路是晴天的白天，水面有波光和焦散，远岸有灯塔（`美术和声音.md`「画面」，水和船照用户认过的那一版不改）。

### 路线上的每一屏

摆在哪、怎么动不在这里定，做进游戏以后在游戏里打磨。

- **标题：** 平时看到水面上看着沉船的画面、游戏名、开始（有存档时是继续和新的一局）、自动演示、设置。
- **打捞那一屏（开船和下网同一屏）：** 平时看到油条和数、这一网的作业油、货格和件数、测深图、钱、方向箭头、每一处打捞点上的箭头（铜色够得着、灰的够不着、绿的点好的下一处）、白圈、模式牌、画面下方新手要的几个键（做过一样收起一样）。从小段 4 起：吊机手在下网时模式牌写着是他在下，他挑好的那一处箭头上有他的小头像。指着打捞点才亮出：那块小牌（按哪个键、按了是什么、捞得到几件、这一网的油、圈的颜色是什么意思）。不显示：海底东西的名字和价钱、藏着的东西在哪、捞到什么的几成把握。
- **一网一揭、一甲板一起冲：** 平时看到泥包、水、拿水管的船员、这一批的总数；揭晓那一刻亮出实物的名字和价钱。指针收起，只有「按住左键 冲洗加快」那一句。不显示：揭晓以前的名字、价值。
- **收获单：** 平时看到一件件实物和签（名字、从哪儿捞的、多少钱）、这一趟的总数、比上一趟（第二趟起）、这一趟做到的事、进港。不显示：总数是怎么算出来的。
- **债本：** 平时看到还欠的总数、四页（第几页、要还多少、这一页攒到多少、锁和海名）、手上的钱、底下的按钮（还这一页，或还差多少；合上）。指着一页才亮出「还清后开放」哪片海。还清的那一页翻过来是那片海的画和名字。不显示：利息、期限（没有）。
- **船坞：** 平时看到地名、钱、债本牌子（钱够还一页时亮）、船上每一样一块牌子（图标、几级、价签）、出海。指着一块牌子才亮出那一样的卡。不显示：每一样往后几级的整张表。
- **暂停：** 这里叫什么、全部的键、继续、回港、回到标题。

### 要配表跟上的（下一轮「这一段的数和字」写）

- 吊机手的价钱：第二潮回来手上的钱刚够雇他，雇完只剩一点。
- 债本第一页：三潮的收成（第三潮带着吊机手和最后那盏灯）回来刚好够还；现在的第一页是三小段那一轮先定的，三潮够不着。
- 第三潮的海底：坡上那盏铜灯半露着，紧挨一截露角的船材，从船边看得见、是橙圈；那一网扣完，油不够再下一网。
- 字：吊机手那张卡、模式牌上他在下网那一句、债本还清翻过来那一面、小段 4～6 的段名（手机上挑段看用）。

### 这一版不做的

- 领航、第二台吊机、更大的船舱和一船舱一起开、船队、不在的时候也在捞：`玩法.md`「自动打捞和船队」、`节奏和难度.md`「从手动到自动」。
- 网、油箱、甲板、水泵以外的设备（网齿和配重、吊臂、绞车、缆长、引擎、声呐、灯、船舱），吊机手升级：`玩法.md`「设备：船坞」。
- 锈钟峡和后面几片海、海图、新海的第一趟：`总览.md`「骨架」、`世界和内容.md`「每片海怎么摆」。路线到翻出锈钟峡那一页为止。
- 结局：`总览.md`「骨架」。
- 船队总览、跟着另一条船看的镜头：`玩法.md`「镜头」。
- 手柄右摇杆在打捞点之间跳：`平台和发行.md`「手柄」（键鼠照常玩）。
- 自动演示后面几段（吊机手以后的船队、锈钟峡、无光层）：`平台和发行.md`「自动演示」。

### 自己玩一遍

看的人点「开始」就是同一条路线：同样的三潮、同样的海底，键是 `平台和发行.md`「键鼠」那一套。路线上演示做的选择（买哪几样、最后一网下在哪）自己玩时可以不一样；不一样的，钱少一点、多一点：差一点的再出一趟就够还第一页，路线上的每一样照样都碰得到。
