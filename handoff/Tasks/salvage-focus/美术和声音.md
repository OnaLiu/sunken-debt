# 沉债 · 美术和声音

这一份放美术方向、画面管线、会动的东西怎么做、界面风格和声音；不放玩家要从画面里读出什么（在 `信息.md`），每一刻要什么感受（在 `时刻和效果.md`）。

---

## 画面

- 3D（用户定的）。
- **画面：** 照现在这一版：3D 场景先画在 640×360 上、整数倍放大的像素管线，卡通光照、水下衰减、焦散、描边；水和船不改。深海靠这一套往暗里走，灯照到的地方才有颜色。水和船就是现在这一版的样子（用户定的）。
- **画风已定，不再挑：** 就是美术库里的「琉璃浅湾」（`art-library/liuli-qianwan/`，看 prompt 用 `art_lib.py prompt liuli-qianwan`），这一套就是从这款游戏收进库的；他认过的样子是 `对比/d/` 那一版跑起来的画面（他 10-17 说：「我感觉这版的水和船效果都非常好」）。效果图就是这一版，不另出画风方向和效果图；新海、新设备、船坞照这一套往外画，和 `对比/d/` 放在一起不掉档次。
- **天光：** 归潮沙湾一路是晴天的白天，一趟一潮天光不变：这一潮和上一潮不一样，看的是海底换了一批货、出海时说一声新的一潮，不靠换天、换时辰；越往下越暗靠水，不靠天。水和船是他认过的那一版，换天会把它一起换掉。后面几片海各有自己的天光，在那一片的设计里定。
- **会动的都用代码画、代码驱动：** 船员、蟹、鱼群、大轮廓，以后新海的活物、船坞里装设备的船员，样子和每个动作都是代码画、代码算的，不用逐帧图、精灵表、视频，也不从动作库拿动作。

船坞、债本两屏用现在铜铁面板、像素圆、小图那一套画（两屏放什么在 `信息.md`）。
