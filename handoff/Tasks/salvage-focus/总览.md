## 一句话

**背着一笔还不清的债出海打捞：先亲手一网一网地捞，后来船员替你捞、整支船队替你捞；设备越来越好，一趟捞得越来越多，海越去越深，捞上来的越来越值钱，也越来越诡异。每一包都裹着厚泥，冲开才知道是什么：从一网一网地揭，到一甲板一起冲，到一整船舱一起开。**

他的三句话落在哪：

| 他说的 | 游戏里是什么 | 在哪一份 |
|---|---|---|
| 开始手动打捞 | 第一趟就是现在打磨好的那一趟：从港外开船出发，顺着船板找到沉船，自己挑地方下网，近景冲泥揭宝，银币匣压轴。之后一网压成「挑一处、按一下」。每到一片新海，第一趟也要自己开、自己找 | `节奏和难度.md`「从手动到自动」、`玩法.md`「手动打捞」 |
| 后面自动打捞 | 雇吊机手：船一停，他自己挑地方下网；雇领航：船自己沿走熟的航线开；再买船，整支船队自己出海、自己回来，你关掉游戏它们也在捞 | `节奏和难度.md`「从手动到自动」、`玩法.md`「自动打捞和船队」 |
| 设备越来越好，越捞越多 | 回港在船坞里一样样升级，每一样都装在船上看得见：网口大一圈，一网多罩几件；吊臂转得更快、伸得更远；油箱大，一趟更长；网更重，挖得更深；灯和声呐看得更远；船舱更大。作业深度够了，才开得进下一片更深的海 | `玩法.md`「设备：船坞」、本份「骨架」 |

## 卖点：凭什么让人记住

**让人记住的两样东西（同类游戏都缺一样让人记住的）：**

1. **揭宝就是每一份产出的奖励。** 别的纯增量里数字是自己跳上去的；这里每一份收获都是一团裹着厚泥、旧网和碎壳的东西，冲开才知道是什么。规模越大，揭得越大：一网一网揭 → 一甲板十几包一起冲 → 一整船舱几十上百包一起开，最贵的那一件永远压轴。揭的那一下是现成打磨好的（`时刻和效果.md`「揭宝的三种规模」）。
2. **诡异的深海就是进度条。** 越往深处，海越暗，捞上来的越值钱，也越不对劲：浅湾里只是一艘沉了的商船和一个逆流游过去的大轮廓；再往下，每条沉船的船头都朝着岸；再往下，捞上来的东西刻着你自己的船名。玩家会一直想知道下一片海底下是什么，和这笔债到底是欠谁的（本份「骨架」、`世界和内容.md`「债的故事」）。

另外它**看起来是真的**：水和船就是他说「非常好」的那一版；海底看得见的东西真的在海底，捞走就少了一件；「自动」不是数字自己跳，是甲板上的船员真的扳着吊机、船真的在海上开。

## 一行产品

**游戏多长：** 玩到还清债三到五个小时，还清以后可以接着捞，不清零重来。他问「增量游戏都这个时长吗，应该卖多少钱，从最大利益看是不是最合理」。答他的：Steam 上有结局、卖得好的纯增量多在两到六个小时（Nodebuster 约 3—6 小时、A Game About Digging A Hole 约 2—4 小时），长的十几个小时（Gnorp Apologue），没有结局一直玩的多是免费的；三到五个小时过了 Steam 两小时的退款线，四片海做得完，所以照这个做。他听完说「可以，就按你的建议做」：时长照三到五个小时。

## 参考简报

- 起点是现成的打捞玩法演示：2026-10-14 到 10-18 打磨好的打捞玩法演示（源码在 `对比/d/`）整个接着用：它就是这款游戏的第一趟、每一网的样子和每片新海的第一趟。演示那一版的设计在 Git 历史里，留下来的细节都并进了这几份。那一版打捞玩法的细节（现在的游戏就是照它做的）管每一网的样子、第一片海的样子和每片新海的规矩；和增量的大结构冲突的地方以增量的大结构为准。
- 同类：一趟有尽头、下一趟更强，是近几年 Steam 上卖得好的纯增量常用的结构（`玩法.md`「核心循环」）；有结局的纯增量的时长见上面「游戏多长」。
- 当时另一个对话给他的理由（他听过，没有逐条拍板）：冲掉厚泥才知道捞上了什么，正好当每次产出的奖励，能从一网一网揭放大到一船舱一起开；越往深处捞上来的越值钱、越诡异，深度就是进度条；「沉债」接得上背着债出海；现在的手动打捞可以当开头，但要压成选个点、按一下，接上他以前提过的自动锁定打捞位置；纯增量卖得好的都有一样让人记住的东西，这一款靠揭宝和诡异深海。

## 规模

一整款纯增量游戏：有存档、船坞、升级、债、船队、几片海（11-21 他定把沉债改成纯增量）。

**先做哪一段给他玩：** 先做前 15—20 分钟，给你玩一遍：现在的第一趟 → 第一次开舱、翻开债本 → 船坞里升三四样 → 「挑一处、按一下」的亲手捞两三趟，一趟比一趟多 → 第一次一甲板一起冲。这一段决定这款增量好不好玩：玩完想不想再出一趟。它点头了，再往后做吊机手、领航、船队和新海。

## 骨架

**核心玩法：** 出海 → 捞 → 开舱 → 船坞 → 还债 → 再出海（每一步在 `玩法.md`「核心循环」）。手上的事从「这一网下在哪」一路变成「下一笔钱花在哪」（`节奏和难度.md`「从手动到自动」）。

**分几段：** 四片海，一片比一片深。他 11-21 定了照这四片做：归潮沙湾 → 锈钟峡 → 无光层 → 债底。每片海怎么摆、海底有什么，在 `世界和内容.md`。

| 海 | 深度 | 第一眼看到 | 捞的是什么 | 诡异的那一样 | 要什么设备 |
|---|---|---|---|---|---|
| 归潮沙湾（现有） | 浅滩到深槽，0—30 米 | 通透浅滩、侧卧在缓坡上的中世纪商船、往下的深槽 | 铜筒、陶罐、铜锅、箍桶、货袋、铜印、铜灯、银币匣 | 一个逆流游过去的大轮廓，小鱼先散开 | 起步就有 |
| 锈钟峡（新） | 30—120 米 | 一道窄峡，几十条不同年代的沉船叠着躺，偏蓝、只看得出大结构 | 船钟、封蜡的信、船首像、成箱的货 | 每一条沉船的船头都朝着岸，和沙湾那条一样；大轮廓经过时，海底的钟自己响 | 缆长、灯 |
| 无光层（新） | 120—500 米 | 阳光到不了，只有自己的灯照亮的一圈；灯外偶尔有别的光 | 不该在这么深的东西：港口的东西、刻着船名的铜牌 | 捞上来的铜牌刻着你自己的船名；那个大轮廓就躺在这里，海底的一道「山脊」是它的身子 | 灯、声呐、更深的缆 |
| 债底（新） | 最深处 | 沉船排成一行一行，像账本上的字 | 一页页债契 | 账本最后一行 | 最深的缆 |

**几段共用的：** 见下面「系统表」和本份末尾「现有的每一样怎么用」。

**结局：** 还清最后一页债就是结局。还清最后一页，那个大轮廓从债底游上来，把你的船轻轻放回港口。

## 不做的

- 不做清零重来（换来永久加成的那种重开）：这款有结局、几个小时玩得完，靠一片片新海往前走，清零重来只会拉长、不会更好玩。
- 「6—8 个网位都捞过就替玩家收工」不再用：增量里一趟要靠设备变长，捞完一片海就收工会让升级没处使。
- 「重来一趟海底一模一样」不再用：第一趟以后每一潮重铺。一模一样的海捞第二遍就没有新东西了。
- 不为手机另做玩法、不做触屏操作（`平台和发行.md`）。

## 现有的每一样怎么用

| 现有的 | 这款游戏里怎么用 |
|---|---|
| 水、船、天空和灯塔、像素管线和材质（`world/water`、`world/boat`、`world/sky`、`render/`） | 照原样，是整个游戏的样子。船上的设备升级在现在的船模型上加部件（更大的吊机、第二台吊机、灯、油桶、声呐罩） |
| 地形、沉船、断桅残帆、摆放（`world/terrain`、`wreck`、`wreckExtras`、`layout`） | 第一片海归潮沙湾原样；第一趟的摆放一样不改。之后每一潮按同一套「来源 → 散落」重铺散货；新海用同一套代码生成新的地形和沉船 |
| 打捞物模型和泥壳（`world/items`） | 照原样；新海加新的东西，同一套做法 |
| 海底的东西、看得见判定、圈的预告（`itemsys`、`sight`、`forecast`） | 照原样，白圈只吸到看得见的打捞点上；声呐和灯升级就是放宽「看得见」 |
| 白圈和机械吊臂（`arm`） | 吊臂的机械手感照原样；白圈改成吸到打捞点、在点之间跳（`玩法.md`「手动打捞」）；吊臂速度、伸距成了升级项 |
| 网的下放、闭合、提起、转回（`netop`、`collide`） | 照原样；时长成了升级项；第二台吊机多一份 |
| 网包泥团（`bundle`） | 照原样；成了「一份产出」：可以码在甲板上、送进船舱，攒着一起冲 |
