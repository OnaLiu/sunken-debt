## 画布

**只做一版：** 固定 1920×1080、16:9 横屏，在电脑上玩（用户定的）。窗口整体等比缩放留边，看见的世界范围不变；键鼠和手柄都能玩。手机、平板打开只放自动演示，手指点一下只能暂停、挑看哪一段，竖着拿时提示横过来、看得到「自己玩请在电脑上打开」，不做触屏操作。

## 键鼠

整个游戏一套，每一段都一样：

| 键 | 做什么 |
|---|---|
| 鼠标 | 指向打捞点，白圈和吊臂过去；指针一直看得见，不锁鼠标 |
| 左键（或空格） | 在指着的那一处下网；网在水里时点好下一处，再点取消 |
| W（↑） | 油门，开船，随时 |
| S（↓） | 刹车；停住接着按是倒船 |
| A D（← →） | 转向：按 D 船头往右、按 A 往左；前进、倒船、停着都一样 |
| 按住左 Shift | 镜头拉近看鼠标指着的海底，松开回原来的镜头；停着、开着、网在水里都行（冲洗、揭宝、开舱时不管事） |
| 按住右键拖 | 停着时看四周（网在水里也行）；开着船镜头只跟船，鼠标不管，一开船就转回船后 |
| 滚轮 | 拉近拉远 |
| E，或点甲板那一排的「开冲」 | 现在就开冲 |
| 按住左键（或空格） | 冲洗、开舱加快（这时指针收起，不挡着揭宝） |
| 按住 Q | 回港 |
| Esc | 暂停 |

船坞和债本里（三小段里就是这样）：鼠标指着船上一块牌子就看那一样，A D（← →）也能一样一样换；点卡上的按钮或按空格买下、雇用；E 出海；Q 翻开债本。债本里点「还这一页」或按空格还；Q、E、Esc 合上（第一次翻开时那个按钮是「去船坞」）；船坞里按 Esc 暂停。

## 手柄

左摇杆开船（推前油门、拉后刹车倒船照载具求生；推左右转向和键盘 A D 同一套：推右船头往右、推左往左，停着也转）；右摇杆在打捞点之间换（看不到打捞点时转镜头）；A 下网，Y 开冲，按住 A 加快，按住 B 回港。

## 自动演示

- 一个入口，点一下就从头自己玩，用的就是玩家的键（演示时屏幕上亮出这一刻按的键和鼠标，跟着正在看的地方；鼠标指针画出来，指到哪看得见，一甲板一起冲的时候收起），不瞬移、不发奖、不读藏起来的东西。
- **第一段照现在：** 从港外航路开始，找到沉船，下几网，银币匣揭晓，船员搬运，收工开舱，长度不改。
- **后面接几段（新）：** 每一段从一份存好的进度开始，各一分钟左右，让看的人看见增量的后面：船坞里升级、船员装上新设备 → 吊机手和甲板码包、一甲板一起冲 → 船队在锈钟峡、一排船舱一起开 → 无光层里只有灯照着的一圈。手机上看演示时能挑看哪一段。
- Esc 随时接管，接管的是这一段的进度，机器人不再接回。
