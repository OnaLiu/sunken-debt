# 沉债 · 上手

这一份放怎么教：玩家在哪一处学会什么；不放那一处长什么样（在 `世界和内容.md`「三处现场」），操作本身（在 `玩法.md`「操作」）。

---

## 操作怎么学会

- 不讲、不拦：一打开就能指、能点，没有教程页和弹出来的整段说明。
- 看得见的打捞点上方的箭头告诉玩家哪里能捞；指上去，小牌写「左键 下网」，够不着的写「WASD 开近」；网在水里时指上去写「左键 下一处」。
- 画面下方那一条写着第一次要用的键：鼠标指向打捞点、左键下网、W S 前进 刹车倒船、A D 转向、滚轮拉近拉远（W S 的手感和键照载具求生，开过那一个的人不用学；A D 按哪边船头就往哪边转，停着也转，不用学）。自己做过一样就收起一样，再来一次也不再出。
- 第一包码上甲板时，甲板那一排底下说一次「码满自动开冲」；开冲的键（E）一直在那一排上。
- 开冲的时候那一条写「按住左键 冲洗加快」。
- 记不清按什么，Esc 暂停，右边列着全部的键（按住左 Shift 看清海底、停着时按住右键看四周也在里面）。

## 第一趟：三处现场各教会什么

| 现场 | 这里教会什么 |
|---|---|
| 通透浅滩 | 看实物挑地方；海里的东西和甲板上的收获一一对应 |
| 沉船（断舱船腹） | 沉船有空间，生物会改变线索 |
| 下坡（向下的深槽） | 从看得见的实物平滑过渡到有依据的未知；也是「下面还有什么」的开头，往后接到更深的海 |

## 第一趟以后：新东西第一次出现时

规矩和第一趟一样：不讲、不拦，新东西自己摆在玩家眼前，第一次要用的那一下说一次，做过就收起。

| 第一次 | 玩家怎么学会 |
|---|---|
| 翻开债本 | 第一趟开完舱自动翻开，这是故事的那一下（`世界和内容.md`「债的故事」）；以后要自己翻，船坞里债本那块牌子一直在，键写在牌子上 |
| 船坞 | 不教：船上每一样一块牌子、底下挂着价钱，指着哪块出哪张卡，买不起的卡上说钱不够；买下船员当场装上，看得见买到了什么 |
| 码包 | 第一包码上甲板时说一次码满自动开冲（上面「操作怎么学会」） |
| 吊机手 | 雇他和买设备一样，不另教。雇了以后第一次停稳他下网，画面下方那一条多一行：自己点一处就是你下这一网。你自己点过一次（看见他让开）就收起。他不下的橙圈，指着时小牌上说一句；最后一网他回头看你，靠动作，不加字 |
| 还一页 | 不提示：钱够了船坞里债本牌子亮，翻开以后那一页的按钮从还差多少换成还这一页 |
