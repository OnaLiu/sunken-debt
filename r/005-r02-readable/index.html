它自己的汇报

第 2 轮“一眼看懂屏幕”做完了，改动覆盖航行、作业、揭晓、港口和海图的整个画面。最终打包下，原有验收 49/49 通过，这一轮新写的验收 59/59 通过。实时跑演示 2 分钟共 7202 帧，没有一帧超过 25 毫秒。

12 条要求怎么落地的

  • 阵营阴影： 游戏里没有战斗和敌人，所以分三种颜色。我方船员是青圈，网能兜住的活物是橙圈，兜不了的大型生物是紫圈。生物躲起来、离得远或在深水看不清时，脚下的圈也跟着淡去或消失。
  • 职责与名字： 五个船员按职责分成三种体型、帽子和衣服颜色：船长老魏，冲洗手阿满、小秦，搬运手石头、老蔡。名字写在头顶，颜色对应职责。水下活物揭晓前不写名字，因为设计文档不让提前泄露身份。
  • 能交互的东西：
    • 看得见、网能兜的东西上有浅黄菱形。
    • 看得见但被甲板挡住、网下不去的，用灰菱形带横杠。
    • 埋着的硬物用红三角。
    • 泊位在水面上有金色虚线圈；满油又没东西结算时圈变灰，并写“暂时不用靠”。
  • 伤人前的预兆： 这里会让玩家吃亏的只有三件事，都有预兆。快搁浅时船头前方出现红色虚线弧（实测提前 2.6 秒）。网口压到埋着的硬物时，作业栏先写明。返航油不够时燃油栏闪动提醒。
  • 常驻与暂停：
    • 常驻只有模式和燃油；航行时多一张小海图。
    • 按键提示、作业栏、回波测深、航次账都是用到时飞进来，用完收起。
    • 暂停时这些全部出来。中间是这个地方的图例，航行、作业、揭晓、港口各不相同，一个图标一句话。海图自带图例。
  • 要等的事： 吊臂到位、网的回收、冲洗泥壳、靠泊、补油，都在那件东西旁边挂着“还剩几秒”。网的回收在 6.7 到 25.6 米水深实测，预计和实际差不到 0.1 秒。
  • 字和画面：
    • 字是系统高清中文字体，窗口缩放后按屏幕实际像素重画。
    • 画面固定 1920×1080：窗口怎么拉都只整体缩放、两边留黑；镜头拉远拉近，界面大小不变。
  • 按钮与结果卡：
    • 每个按钮按了都有看得见的结果；不能按的变灰，按了写原因。
    • 每一网都有结果卡（空网也有），停在右边，点一下或按 C 才收起。
    • 港口结算单补满油前，“继续出海”是灰的。

独立审查
我请了一个审查代理按这 12 条挑毛病，它找出 2 条严重、6 条中等、9 条轻微的问题。最严重的两条是：结算单很长时看不全，以及点灰色的“下网”会穿过界面、把落点悄悄挪走。改了其中 16 条，每条都加了回归测试；没改的是下面第一条。另外我自己发现并修了几处，例如在港口暂停时按回车会直接出海。

两处取舍

  • 镜头背对航向时，浅水的红弧要晚一点才进画面；底部的红色文字提示从一开始就有，所以没改。
  • 窗口很小时字会跟着变小，这是“固定 1920×1080、只整体缩放”规则的结果。我没有为此放大界面，改为窗口缩到 60% 以下时，在画面外用正常字号提示放大窗口或全屏。

规则补进了 design.md §10.1；改动、决定和实测写在 notes.md 第 12 节。新增工具：tools/test-readable.mjs（这一轮的验收）、tools/ui-tour.mjs（逐个画面截图）、tools/crisp-shot.mjs（检查字清不清）。

为了构建和测试，我从本机 npm 缓存离线装过依赖，结束时删掉了，开发文件也已删除。要重跑，先 npm ci --offline，再 npm test。全程无头运行，没有联网推送。

这一轮收到的 prompt
这是第 2 轮打磨：让玩家一眼看懂屏幕。游戏和设计文档都在当前文件夹。
范围：航行、作业、揭晓、港口和海图的整个画面。

- 人多的战斗里，每个单位脚下有阵营阴影，我方和敌方颜色明显不同。
- 职责不同的单位一眼分得开：体型、轮廓、颜色，有名字的头上写名字。
- 能交互的东西一眼看得出能交互，和不能交互的背景分得开，不用走过去试。
- 伤人的东西出手前有看得见的预兆；没露过面的东西不伤人，屏幕外的打不到玩家。
- 屏幕上只常驻玩家一直要看的东西；其余用到时飞进来、用完收起来，暂停时全部出来。
- 每个地方的暂停说那个地方玩家要懂的东西，不同地方说的不同：这一屏和小地图上每个小图标代表什么，这里能按的键；一个图标一句话。
- 字用高清字体，按屏幕原来的分辨率画；画面是像素风，字也不用像素字。
- 要等的事（建造、施工、开箱、救人、冷却）在它本身上一直看得见还剩多久。
- 字不被屏幕边切掉，不压别的字和按钮。
- 画面按 1920×1080 固定：窗口拉宽缩窄、全屏和窗口来回切，能看见的世界范围不变，只整体缩放、两边留黑；镜头远近和界面分开，界面大小不变。
- 每个按钮按了都有看得见的结果；不能按的变灰，按了说原因。
- 没有倒计时的选择不会自己跳过；结果卡等玩家点了才收起。
