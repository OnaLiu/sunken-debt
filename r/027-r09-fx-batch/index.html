沉债 · 先看这一轮变了什么；能玩的是最新一版。

这一轮变了什么

收获单：改前按下收工，一张卡片立刻整张弹出来、数字一下写满；改后船员先停手转身看镜头、镜头退远，暗幕落下、单子升起，一行一行“嗒”地滑进来，珍品那行停半拍带一道金光，总价从 0 滚上去，滚到头盖一个朱红的章，“再来一次”最后慢慢亮起。

收工的样子（先捞完，再油尽）：改前只是两声不一样，单子马上弹出来盖住船；改后先在船上演完——捞完是汽笛、白汽、舱口一亮、大家举手，油尽是烟囱咳出两团黑烟、熄火滑停、船员看看烟囱再耸肩——单子等这些做完才落下。

空网：改前网包落下来只有一声和一张小卡；改后网口一松泥水哗地浇在格栅上摊成一片、几缕水草挂着，慢慢渗掉，最近的船员两手一摊耸耸肩。

再来一次：改前单子一关，新的一趟从停着的船开始；改后车钟叮叮、单子往下滑走，黑场一下，黑幕从下往上抹开时船已经带着航迹在走，界面晚半拍才出来。

它自己的汇报

第九批四个编号（C11 收获单、C12 三种收工、C3 空网、D1 再来一次）都做完了，整套测试完整跑了一遍，128/128 全部通过。

这一轮改了什么

  • C11 收获单（标志时刻 S4）：按清单写的五拍做。
    • 船员先停下手上的事、一个接一个转身看镜头，镜头退远，船放到画面右边。
    • 暗幕落下，航行时的界面一起淡掉，收获单升起。一行一行“嗒”地滑进来，越往下音越高；珍品那行先停半拍，进来时带一道金光。
    • 总价从 0 滚上去，滚到头盖一个朱红的章，分满载、油尽、收工三种。
    • 盖完章，珍品那行的金菱形再亮一次；“再来一次”最后慢慢亮起。
    • 亮起来以前按 Ⓐ 会直接跳到盖章，亮了以后再按才是再来一次。
  • C12 三种收工：船上先演完，收获单才落下。
    • 捞完：汽笛、白汽、舱口满满一亮，大家举手。
    • 没油：烟囱咳出两团黑烟，熄火滑停，船员抬头看烟囱再耸肩。
    • 中途收工：大家转过来点点头。
  • C3 空网：一股泥水浇在格栅上摊开，挂着水草，几秒里慢慢渗掉；离得最近的船员两手一摊耸耸肩。
  • D1 再来一次：车钟叮叮，单子滑走，黑场里新的一趟先开起来。黑场量到 0.43 秒，要求是至少 0.4 秒。黑幕从下往上抹开时船已经带着航迹在走，界面晚半拍才出来。
  • 顺手修了一个原来就有的泄漏：以前每开一趟，旧世界的几何体留在显存里，大约 170 个一趟，从不释放。第一次跑整套时，效果单连放 131 张就把页面撑崩了。现在换一趟时把旧的放掉，一直稳在 150–220 个。这个泄漏改前版本也有，但它正好落在“再来一次”上，所以在这一批里修了。修完又完整跑了一遍整套。
