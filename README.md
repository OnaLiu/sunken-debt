# 沉债 · SUNKEN DEBT

3D 诡异海洋的纯增量打捞游戏：背着一笔债出海，先亲手一网一网地捞，后来船员和船队替你捞；设备越来越好，一趟捞得越来越多，海越去越深，捞上来的越值钱也越诡异。每一包都裹着厚泥，冲开才知道是什么，从一网一网地揭到一整船舱一起开。固定设计画布 1920 × 1080，按窗口等比缩放并留边。现在仓库里能玩的是打磨好的打捞玩法（这款游戏的第一趟），纯增量的设计用户 2026-11-21 点了头，照它开做。

- 设计文档：[打捞玩法设计](handoff/Tasks/salvage-focus/打捞玩法设计.md)，唯一的一份，设计线原地改它。
- 2026-11-21 起照金牌制作人第八版做（`主链.json`）：设计、开发、运营三条线，看门脚本照第八版的图排下一格；家在 Mac mini（`主链.json` 的 `home`）。
  - 游戏文件夹 `salvage/`：游戏本身在 `salvage/game/`，从他认过的 `对比/d/` 那一版接着做（构建 `npm ci && node tools/build.mjs`）。
  - 设计线 `design/`、网站（总台）`site/`、账本 `进度/`；四段：归潮沙湾、锈钟峡、无光层、债底。
  - 换一台电脑接上：拉下库以后在库根先跑 `python3 <技能目录>/scripts/rounds.py new design --chain 设计 --doc handoff/Tasks/salvage-focus/打捞玩法设计.md --work . --name 沉债`，再跑 `python3 <技能目录>/scripts/chain.py 主链.json join`（设计是库里原地改的那份，`design/game.json` 不进库，光跑 `join` 开不出设计线和游戏文件夹）。看在哪一格：`chain.py 主链.json v8`。
- 以前的东西留着不动：`index.html`、`r/`、`轮次/`、`设计文档.html` 是金牌制作人 L3 的旧轮次网站（`l3site.py` 生成，本地打开 `index.html` 看）；`对比/d/` 是他 2026-10-17 认过的那一版；`play/` 是 10-15 合并效果那一版的旧游戏文件夹。
