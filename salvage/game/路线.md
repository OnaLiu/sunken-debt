# 沉债 · 第一段·归潮沙湾 路线（六小段）

三小段（`三小段.md`）后面接着三小段，合起来是切片「第一段·归潮沙湾」那一整圈（`handoff/Tasks/salvage-focus/切片.md`，路线表 `路线表.json`）：

1. **第一趟** — 开船顺着线索找到沉船，一网一揭（三小段）。
2. **开舱、债本、船坞** — 收成变成钱，钱变成船上看得见的设备；原来背着债（三小段）。
3. **第二潮** — 海底重铺过，码满一甲板一起冲（三小段）。
4. **吊机手** — 第二潮回港，第二次进船坞：扳吊机的那个船员头上多一块牌子，雇他（2500）。他戴上手套，吊机前立起带顶棚的座子，他坐上去握住手柄。出海以后船一停稳，他转头看一处，那一处的箭头上顶着他的小头像，停一拍，白圈跳过去、吊臂转过去、网落下去。你只管开船、停在哪；码满照样一起冲。
5. **最后一网** — 第三潮快到头，油只够再下一网：模式牌写「油只够一网」，心跳快起来。他挑好船边那一小堆碎陶片，回头看你一眼（比平时多停一拍）。坡上一处橙圈：泥里半露着一盏铜灯，紧挨着一截埋着的船材；他不下那一处（小牌上写着）。你指着它左键，他松开手柄往后让一步，这一网是你的。网往坡下沉，那个大轮廓从深槽里游上来、从船旁边过去，网触底刮到船材，网架一震、扬起泥，往回收。灯还在：这一网码上去甲板正好满，开冲，铜灯压轴。油不够再下一网，自己收工。
6. **还清第一页** — 开舱，这一趟比上一趟多；进船坞，右上「债本」那块牌子亮着（钱够还一页）。按 Q 翻开，点「还这一页」：盖章，这一页翻过来，背面是下一片海「锈钟峡」的画（一道窄峡，几十条沉船叠着，船头都朝着一个方向），写「已还清 · 锈钟峡敬请期待」；还欠的总数少了一截。合上，船停在码头，换了一身设备、吊机前坐着吊机手。演示到这里回到标题。

## 怎么玩到

- 自己玩：`index.html` → 开始，一路玩下来（第二潮回港进船坞就有吊机手的牌子）。
- 直接到某一小段：`index.html?seg=4`（吊机手：第二次进船坞，手上 2800）、`?seg=5`（最后一网：第三潮，雇了吊机手，船停在沉船船尾外，油 11，甲板上码着 4 包）、`?seg=6`（还清第一页：第三潮的收获单，进港以后手上 3300）。后面加 `&demo=1` 是演示从那一小段开头接着放。
- 自动演示：标题上选「自动演示」（`index.html?demo=1`），从第一趟一路放到还清第一页、回到标题。按 Esc 接管。手机、平板打开同一个地址直接放演示，点一下暂停可以挑六小段里的哪一段。

## 键（新加的）

- 雇了吊机手以后：船停稳他自己下网；你指着一处左键，这一网就是你下（他在那一拍里就松手；他的网在水里时你点的那一处排在下一网）。按 W A S D 开船他就松手。
- 债本：钱够时底下是「还这一页」（空格或左键）。
