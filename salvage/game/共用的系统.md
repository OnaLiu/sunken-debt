# 沉债 · 共用的系统（整个游戏一份）

四片海（归潮沙湾 → 锈钟峡 → 无光层 → 债底）用的是同一套开船、下网、开冲、收获单、一局、船坞、债本、镜头、活物、演示的手、界面、效果和声音。玩家从一片海开到下一片海，这些东西一个样子、一个手感、一样的成色；改一处，每片海自己玩和演示里都跟着变。

每片海只交自己的内容：海底的形状、沉船和线索摆在哪、每一潮冲出来什么、事件和路线（到了哪、箭头往哪指）、表里的字和数。这些都放在 `src/sea/<这片海>/` 一个文件夹里，共用的系统只从 `src/sea/index.js`（「当前这片海」）拿，不直接认哪一片海的文件。

2026-11-26「共用的系统收成一份」那一格把第一段·归潮沙湾三小段里的这些分开了；玩家看到的、玩到的一点没变（试跑对过，见 `notes.md` 同名那一节）。

## 每片海交什么

归潮沙湾的在 `src/sea/shawan/`，`index.js` 开头列着每个文件放什么。后面的段照它交一份同样名字的：

- **摆放**（`layout.js`）：出港点 `START`、航路浮标 `LANE_BUOYS`、船开不过去的 `OBSTACLES`、主沉船 `WRECK` 和 `wreckToWorld`、深槽 `trenchZ`、大轮廓的路 `LEVIATHAN_PATH`、埋着的硬物 `HIDDEN_TIMBER`、网位 `NET_SPOTS` 和 `SPOTS_TO_END`、捞得到的东西长什么样 `ITEM_SHAPES`、这一趟海底有什么 `seabedItems(tide)`、蟹 `CRABS`、海鸥多的地方 `GULL_AREAS`、装饰让开的地方 `DECOR_AVOID`。
- **海底**（`seabed.js`、`decor.js`）：`seabedY`、`seabedColor`、`TERRAIN_BOUNDS`、`GROUND_SITE`、`buildDecor`、`buildMarks`。
- **沉船**（`wreck.js`、`wreckExtras.js`）：`buildWreck`、`buildWreckCollider`、`buildWreckExtras`、`floorPoint`。锈钟峡几十条沉船叠着躺，到那一段让 `buildWreck` 交回几条；碰撞、网下得去下不去、看得见判定都按「沉船」认，不按哪一条。
- **一潮**（`tide.js`）：`tideLayout(n)`，用 `game/tide.js` 的 `tideBench` 铺。
- **事件和路线**（`story.js`）：`story.update`（到了哪、什么时候演哪一下）、`story.lead` / `leadNext`（箭头指哪）、`story.placeName`（暂停页上这里叫什么）、`story.nearTrench`、`story.known`（已经认得这片海了）、`placeOf`（收获单上这件从哪儿捞的）。
- **表**：这片海的地名、地点、捞获、每一潮的数加进配表，游戏读表。
