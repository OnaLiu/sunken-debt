# 沉债 · 第一段·归潮沙湾 三小段

## 这一版是什么

小样那一刻往后接两段，接成游戏反复走的那一圈：

1. **停在沉船旁，捞**：挑一处按一下、码满甲板、一甲板一起冲（小样原样）。冲完一甲板，结算那一张写「接着捞」或「回港」。
2. **回港开舱、翻开债本**：甲板空着按住 **Q** 就回港开舱；收获单之后翻开债本，钱够就「还这一页」，盖章、翻页，下一片海标上海图（本试玩版未开放）。
3. **船坞升设备、出海**：船停在码头，点船上设备的牌子，升网（网口大一圈）或油箱（驾驶室顶上多一只油桶）。「出海」回到沉船旁，第二潮，沉船旁多铺了一些东西。

## 怎么看、怎么玩

- 自动演示：`demo.html`，一整圈约 4 分钟：捞两甲板 → 按住 Q 回港 → 债本 → 船坞升网、升油箱 → 出海 → 第二潮捞一甲板。按的键亮在指针旁，按 Esc 接管。
- 自己玩：`index.html`，键鼠。
  - 捞：和小样一样（左键下网、WASD 开船、左 Shift 看海底、E 开冲）。
  - 回港：结算那一张点「回港」，或甲板空着时按住 Q。
  - 收获单：空格接着走，最后「翻开债本」。
  - 债本：点「还这一页」；点右下那一块去船坞。
  - 船坞：点船上的牌子看设备、点「升级」；「翻开债本」回去还债；「出海」或 E 出海。
- 原来那一整趟：`index.html?trip=1`。
